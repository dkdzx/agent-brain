# agent-brain v0.4.1

This patch release keeps the v0.4.0 public anonymous dashboard contract and
fixes the interactive DAG zoom path.

## Fixed

- Mouse-wheel zoom now updates only the existing DAG canvas transform and the
  viewport scroll anchor.
- The point under the cursor remains the zoom anchor.
- The outer project list, summary metrics, task inspector, tables, and event
  stream are not rebuilt for each wheel step.
- Zoom buttons use the same local update path and zoom around the viewport
  center.
- Wheel propagation is stopped at the DAG viewport so the page does not
  compete with the graph interaction.

## Verification

- Public Python compile check passed.
- Full public unit-test suite passed: 34 tests.
- Public-tree private-marker audit passed after excluding the ignored local
  `.demo-runtime` generated by the local demo server.
- Browser smoke test confirmed that wheel zoom changes the canvas transform and
  scroll position while summary, project-card, and inspector text remain
  unchanged.

The release remains read-only and uses anonymous synthetic demo data only.
